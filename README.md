# Proportfolio

Static portfolio site for Shantanu Mishra, DevOps Engineer and Full Stack Developer.

## Files

- `index.html`
- `styles.css`
- `script.js`

## Deploy on Netlify

1. Sign in at [Netlify](https://app.netlify.com) with GitHub.
2. Add new site → Import an existing project → GitHub.
3. Select `Shantanu20k/Proportfolio`.
4. Leave the build command empty and set the publish directory to `.`.
5. Deploy.

No build step is required. Netlify serves `index.html` from the repository root.
